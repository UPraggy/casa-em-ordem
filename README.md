# Casa em Ordem

Painel amigável para organizar compras, estoque, orçamento e cuidados essenciais da casa.

## Rodar localmente

```bash
python -m http.server 4173
```

Abra `http://127.0.0.1:4173`.

Os dados ficam salvos no `localStorage` do navegador. O cadastro aceita foto do item, preço, quantidade, estoque mínimo e data de validade. A lista de compras pode ser exportada em CSV.
